# Telegram Boost Bot v3.3

Панель управления **несколькими Telegram-аккаунтами** (мульти-аккаунт без лимитов) на двух движках:

- **Бот (Bot API / aiogram 3)** — интерфейс: меню, кнопки, live-прогресс, статусы задач.
- **Загруженные аккаунты (MTProto / Telethon)** — все действия выполняются **от их лица**.

> 🔖 Версия печатается в лог при старте (`Telegram Boost Bot v3.3`) и в `/help`.
> Если её нет — запускается старый код (см. «Обновление версии» внизу).

## Возможности

| # | Функция | Как работает |
|---|---------|--------------|
| 1 | **🧩 Мульти-аккаунт** | Загружай **сколько угодно** аккаунтов (номер → код → 2FA). Менеджмент: список, детали, выход. Сессии в SQLite, переживают перезапуск. Миграция со старой схемы «1 аккаунт» — автоматическая. |
| 2 | **💬 Реакции** | Выбор аккаунтов → чаты (несколько за раз) → набор эмодзи (случайная на каждое сообщение) → любой лимит (100/500/1000/♾/**своё число**) → свежесть (24ч/3д/7д) → ⚡️авто-режим. По каждому аккаунту — своя задача со своим прогрессом. |
| 3 | **📸 Стории** | Участники чата с активными историями → посмотреть + лайкнуть. **Работает в чатах со скрытыми участниками**: бот собирает авторов последних сообщений. Лимит участников: 300/1000/♾/своё число. |
| 4 | **✉️ Сообщения в чаты** | Текст или фото+подпись → в выбранные чаты от выбранных аккаунтов. Паузы между отправками, прогресс, сводка. |
| 5 | **👤 Профиль аккаунта** | Редактирование от лица аккаунта: **имя, фамилия, описание (био), юзернейм, фото** (установка нового / удаление текущего). |
| 7 | **🕵️ Парсинг участников** | Ссылка на чат → все участники (если скрыты — авторы последних сообщений, количество настраивается) с фильтрами: последний визит (24ч/3д/7д/30д), аватарка (есть/нет), юзернейм (есть/нет) → **Excel-файл** (ID, имя, юзернейм, визит, аватар, источник). |
| 8 | **📨 Инвайтинг** | Excel/CSV со списком (@юзернеймы, ID, телефоны) → аккаунт-админ добавляет их в супергруппу: паузы между добавлениями, пачки с перерывом, дневной лимит, стоп при ошибках подряд и PeerFlood, **Excel-отчёт по каждому** (добавлен/причина отказа). |
| 9 | **📋 Мои задачи (ETA)** | Живой статус каждой задачи: ▶️/⏸/✅/🛑/❌ + счётчики + аккаунт-исполнитель. Остановка по одной или всех. Параллельность — `MAX_CONCURRENT_TASKS`. |

## ⚠️ Дисклеймер — прочитай до запуска

- Ты загружаешь **реальные аккаунты Telegram**. Автоматизация нарушает условия Telegram — риск ограничений/бана на тебе.
- Рассылка сообщений — самый «опасный» сценарий: за спам Telegram банит быстро. Используй разумные паузы (`SEND_DELAY_*`) и только по своим чатам.
- Частая смена профиля/юзернейма — тоже триггер для ограничений; Telegram режет частоту (бот покажет, сколько ждать).
- Сессии всех аккаунтов — в `data/bot.db`. **Никому не передавай** этот файл.
- Бот отвечает только владельцам ID из `ADMIN_IDS` — все загруженные аккаунты принадлежат тебе.

## Требования

- Python **3.10+** (рекомендуется 3.12) или Docker
- Токен бота от [@BotFather](https://t.me/BotFather)
- `api_id` / `api_hash` с [my.telegram.org](https://my.telegram.org) → *API development tools*

## Быстрый старт

```bash
cd telegram-boost-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # заполни BOT_TOKEN, API_ID, API_HASH, ADMIN_IDS
python run.py
```

Docker: `cp .env.example .env && docker compose up -d --build`.

## Заполнение .env

| Переменная | Обяз. | По умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | ✅ | — | Токен бота от @BotFather |
| `API_ID` / `API_HASH` | ✅ | — | С my.telegram.org |
| `ADMIN_IDS` | ✅ | — | Telegram ID владельцев через запятую ([@userinfobot](https://t.me/userinfobot)) |
| `DB_PATH` | — | `data/bot.db` | SQLite-база (сессии всех аккаунтов) |
| `REACTION_DELAY_MIN/MAX` | — | `0.8 / 1.6` | Пауза между реакциями, сек |
| `STORY_REACTION_DELAY_MIN/MAX` | — | `0.6 / 1.2` | Пауза между лайками историй, сек |
| `PEER_DELAY_MIN/MAX` | — | `0.3 / 0.8` | Пауза между опросом участников, сек |
| `SEND_DELAY_MIN/MAX` | — | `3.0 / 7.0` | Пауза между отправками сообщений, сек |
| `DEFAULT_MESSAGES_LIMIT` | — | `1000` | Лимит по умолчанию (в боте выбирается свой) |
| `DEFAULT_PEERS_LIMIT` | — | `300` | Лимит участников по умолчанию (в боте выбирается свой) |
| `MAX_CONCURRENT_TASKS` | — | `5` | Сколько задач выполняются одновременно |
| `FLOOD_WAIT_CAP` | — | `300` | Если Telegram просит ждать дольше — задача останавливается |
| `PROGRESS_INTERVAL` | — | `8` | Частота обновления прогресса, сек |

## Как пользоваться

**Первый шаг любой задачи — 🧩 выбор аккаунтов** (если аккаунт один, шаг пропускается):
тапай строки (✔️ = выбрано) → «Готово» или «Выбрать все». **Лимитов на количество аккаунтов нет.**

- **💬 Реакции**: аккаунты → ссылки на чаты (несколько, каждая с новой строки) → набор эмодзи →
  настройки (лимит `✍️ свой` — любое число или `0` = ♾; свежесть; свои сообщения; ⚡️авто-режим) → ▶️.
- **📸 Стории**: аккаунты → ссылки → лимит участников (`✍️ свой` / `0` = ♾) → режим. Скрытые участники — не проблема: бот соберёт авторов последних сообщений.
- **✉️ Сообщения**: аккаунты → текст или фото с подписью → ссылки на чаты → ▶️.
- **👤 Профиль**: выбор аккаунта → меню (имя / фамилия / био / юзернейм / фото / удалить фото). Фамилия и био: пришли `-` чтобы очистить. Юзернейм проверяется на занятость до установки.
- **🧩 Аккаунты** (`/accounts`): список, детали, «➕ Добавить аккаунт», выход из отдельного аккаунта.
- **📋 Задачи** (`/tasks`): статус каждой (аккаунт · чаты · счётчики), ⏹ по id, «Остановить все».

### Форматы ссылок

`@username`, `t.me/username` — публичные · `t.me/+AbCdEf…`, `t.me/joinchat/…` — закрытые (вступит по инвайту) · `-1001234567890` — id чата

### Команды

`/start` — меню · `/accounts` — аккаунты · `/tasks` — задачи · `/stop` — остановить все задачи · `/cancel` — отменить шаг/вход · `/help` — справка

## Архитектура

```
aiogram (Bot API) ── меню, FSM, кнопки, live-прогресс, «Мои задачи», менеджмент аккаунтов
        │  управляет
        ▼
ClientManager ── МУЛЬТИ-АККАУНТ: owner → {account_id → Telethon-клиент}
        │  выполняет
        ▼
TaskRegistry ── параллельные задачи с очередью (Semaphore), статусами, историей
        │   задача = аккаунт × все выбранные чаты
        ├── services/react_service ──── sendReaction + ⚡️events.NewMessage
        ├── services/stories_service ── участники/авторы сообщений → readStories → sendReaction
        └── services/send_service ───── sendMessage / sendFile
        ▼
SQLite (data/bot.db) ── StringSession всех аккаунтов (схема v2 + автамиграция)
```

## Обновление со старых версий

- `.env` и `data/` просто переносим в новую папку — **миграция БД v1→v2 выполнится автоматически**
  при первом запуске, все ранее загруженные аккаунты сохранятся.
- После запуска в логе должно быть `Telegram Boost Bot v3.3`.

## Обновление версии (важно!)

1. Полностью останови бота: `Ctrl+C` (или `pkill -f "python run.py"`).
2. Запускай `python run.py` **из новой папки** — проверь `pwd`.
3. В логе первая строка — `Telegram Boost Bot v3.3`.

## FAQ

**«Сессия недействительна» в списке аккаунтов** — аккаунт разлогинился (например, вышел из всех устройств). Удали его и добавь заново.

**Задача ⏸ «в очереди»** — ждёт свободный слот `MAX_CONCURRENT_TASKS`, стартует автоматически.

**Смена имени/юзернейма не проходит** — Telegram ограничивает частоту изменений профиля; подожди (бот пишет сколько).

**Скрытые участники** — для историй бот автоматически переходит на сбор авторов последних сообщений чата.

**Много ошибок ⚠️** — почти всегда FloodWait: меньше параллельных задач, больше паузы.
